Решение: $ARGUMENTS

1. Сформулируй запись в формате `docs/core/DECISIONS.md`: **Решение / Почему / Что меняет / Отменяет**. Номер — следующий свободный К.
2. Перечисли файлы, которые нужно изменить: `CLAUDE.md` (модули, правила, стек), `README.md`, `docs/core/ROADMAP.md` (журнал изменений), `docs/core/STATUS.md`, код и тесты; `vectors/` — затем `npm run vectors`; `spec/` и `spec/SOURCE.md` — затем `npm run gen:pao`. Приведи сами правки.
3. Укажи влияние на версию по правилу `CLAUDE.md` (патч — исправление, минор — добавление, мажор — ломка) и на потребителей из таблицы «Потребители»: что и в какой их задаче нужно сделать.
4. Если решение отменяет прежнее — пометь прежнее ссылкой «отменено К…», текст не удаляй.
5. Текст решения до записи — комментарием в PR текущей ветки (`gh pr comment N --body-file …`); в окне — только вопрос владельцу.
6. После «да» внеси запись и правки, запусти `npm test`.
