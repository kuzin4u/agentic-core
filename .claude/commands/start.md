description: Начало сессии — прочитать состояние и план, подтвердить задачи
---
Начинаем сессию работы над agentic-core.

1. Прочитай `CLAUDE.md`, затем `docs/core/STATUS.md` (раздел «Следующая сессия»), затем `docs/core/ROADMAP.md`.
2. Проверь рабочее состояние: `git status`, `git rev-parse --abbrev-ref HEAD`, `git log --oneline -5`, открытые PR (`gh pr list`). Если есть незакоммиченные изменения — назови их и спроси, что с ними делать.
   Сверь версию `package.json` на `main` с тегами на `origin` (`git ls-remote --tags origin`): если у версии на `main` нет тега — скажи владельцу и дай готовую команду тега на коммит слияния (как в `/finish` п. 9).
3. Запусти `npm test` (если `node_modules` нет — попроси разрешения на `npm install`). Запиши результат.
4. Сверь план сессии с фактом: всё ли из предыдущей сессии сделано, нет ли новых записей в «Расхождениях».
5. Выведи коротко:
   - этап и номер сессии;
   - задачи сессии с оценкой времени;
   - контрольные точки;
   - что ты прочитаешь в нормах и ТЗ для первой задачи (конкретные пункты).
6. Жди «да» владельца. До «да» ничего не меняй.
