---
description: Проверка изменений на правила пакета (через подагента reviewer)
argument-hint: [путь или ветка; по умолчанию — изменения от main]
---
Проведи проверку: $ARGUMENTS

Передай подагенту `reviewer` изменения и попроси проверить их по чек-листу из его описания. По умолчанию — `git diff main...HEAD`; если есть незакоммиченные изменения (`git status -s` не пуст) — `git diff main` (рабочее дерево против `main`). Результат выведи таблицей: № · файл:строка · нарушение · правило или решение · тяжесть (блокер / важно / замечание) · предложение.

Ничего не исправляй сам. Блокеры предложи оформить задачами через `/task`.
