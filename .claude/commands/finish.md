---
description: Конец сессии — учёт сделанного, ROADMAP, план следующей сессии
---
Завершаем сессию. Перед `/exit` эта команда обязательна.

1. Прочитай `.claude/session-summary.md` (если есть) и `git diff --stat` от начала сессии.
2. Запусти `npm test` и `npm run scan:secrets`. Результаты — в отчёт.
3. Обнови `docs/core/STATUS.md`:
   - «Версия» (и стоит ли тег), «Этап», «Последняя сессия» (дата, номер, часы против оценки), «Модули: готово N из 8», «Тесты», «Векторы», «Поиск секретов»;
   - раздел «Сделано» — что закрыто, с кодами задач (CO-x, К-решения, номера расхождений) и номерами PR;
   - раздел «Заделы» — что перенесено и в какую версию или задачу;
   - раздел «Расхождения» — всё найденное за сессию;
   - раздел «Потребители» — если у потребителя сменилась версия пакета;
   - раздел «Следующая сессия» — заново: команда терминала, задачи с оценкой, контрольные точки, готовые сообщения `/task`, при необходимости `/decision`, и что за владельцем.
4. Сравни фактические часы с ROADMAP. Если этап сдвигается больше чем на одну сессию — предложи правку ROADMAP с строкой в журнал изменений и жди утверждения.
5. Проверь ветку: `git rev-parse --abbrev-ref HEAD` — `task/*`, не `main`. `/finish` коммитится в ветку PR до `gh pr ready`.
6. Предложи текст коммита (на русском, с кодами задач) и жди команды «коммит». Коммит — только после «да» владельца; файлы — явно, без `git add -A`.
7. Сразу после коммита, без отдельного вопроса: push ветки `task/*` (отдельной командой) и проверка `git status -sb`. Ветка не впереди `origin`, в `docs/` нет ` M` и `??` — иначе сессия не закрыта: назови владельцу незакоммиченные файлы и не пиши «готово».
8. Итог для владельца — 5–8 строк: что сделано, что не сделано и почему, что проверить руками, что решить до следующей сессии; номер PR и статус CI. Слияние — владелец.
9. Если PR меняет версию в `package.json` — дай владельцу готовую команду тега на коммит слияния (хэш — из `gh pr view N --json mergeCommit`), в одном блоке: переход на `main` и pull, `git tag vX.Y.Z <хэш>`, отправка тега на `origin`. Тег ставит только владелец; «тег стоит» — только после `git ls-remote --tags origin vX.Y.Z`.
