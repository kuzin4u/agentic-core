# План agentic-core

Порядок — по [`../reference/joint-plan.md`](../reference/joint-plan.md): сначала CO-3, затем CO-1 и CO-2.

| Этап | Содержание | Часов |
|---|---|---|
| 0.1 (сделано) | canonical, journal, holds, idempotency, signing (ed25519), events, money; векторы; 11 тестов | — |
| 0.2 — CO-3 (сделано) | Типы ПАО v1.1, генерируемые из `agent-protocol.yaml` ПС-платформы; клиент ПАО с подписью и повторами по полю `retry`; сервер-заглушка для контрактных тестов; тег v0.2.0. Нужен первым: PS-02 платформы и AG-02 агента | 4 |
| 0.2.1 (сделано) | ПАО 1.2.0 (РП16 платформы): таблица ошибок из `x-pao-errors`, `retry` по ней в клиенте и заглушке; расхождения 2–4 закрыты | — |
| 0.2.2 (сделано) | Расхождение 12: отказ слабых ключей Ed25519 в `ed25519Verifier` (точки малого порядка, неканоническая запись, точка не на кривой); версия-патч без новых экспортов | 0,5 |
| 0.3 — CO-1, CO-2 (следующий) | CO-1: хранилище журнала на PostgreSQL (запрет UPDATE/DELETE триггером, хэш в строке, проверка целостности). CO-2: удержания (условное обновление с версией, тест 20 конкурентных резервов), идемпотентность, nonce; тег v0.3.0. Нужны к PS-05, PS-06, PS-09 | 6 |
| 0.4 | Интерфейс ГОСТ-подписанта (заглушка + адаптер к СКЗИ на стороне оператора) | 2 |
| Каталог — CO-К1, CO-К2, CO-К3 (после 0.3) | Каталог продавца по К8: подмодуль `/catalog` — каноническая модель, валидатор, проверка A5 (CO-К1, 1 сессия); реестр форматов `catalog/formats.json`, порог, тест (CO-К2, 0,5 сессии); коннектор YML и живая проверка цены и наличия (CO-К3, 1–2 сессии, к точке С4 вместе с CO-4). Номер этапа уточнить при ред. 7 совместного плана | — |
| 1.0 | Стабилизация API, тег v1.0.0, подключение во все потребители | 2 |
