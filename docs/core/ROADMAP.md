# План agentic-core

Порядок — по [`../reference/joint-plan.md`](../reference/joint-plan.md): сначала CO-3, затем CO-1 и CO-2.

| Этап | Содержание | Часов |
|---|---|---|
| 0.1 (сделано) | canonical, journal, holds, idempotency, signing (ed25519), events, money; векторы; 11 тестов | — |
| 0.3 — CO-3 (следующий) | Типы ПАО v1.1, генерируемые из `agent-protocol.yaml` ПС-платформы; клиент ПАО с подписью и повторами по полю `retry`; сервер-заглушка для контрактных тестов; тег v0.3.0. Нужен первым: PS-02 платформы и AG-02 агента | 4 |
| 0.2 — CO-1, CO-2 | CO-1: хранилище журнала на PostgreSQL (запрет UPDATE/DELETE триггером, хэш в строке, проверка целостности). CO-2: удержания (условное обновление с версией, тест 20 конкурентных резервов), идемпотентность, nonce; тег v0.2.0. Нужны к PS-05, PS-06, PS-09 | 6 |
| 0.4 | Интерфейс ГОСТ-подписанта (заглушка + адаптер к СКЗИ на стороне оператора) | 2 |
| 1.0 | Стабилизация API, тег v1.0.0, подключение во все потребители | 2 |
